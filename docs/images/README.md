# README screenshots

The overview screenshots show the actual Central interface with six fictional
MQTT climate devices in an isolated installation. Each device has one temperature
and humidity sample. Device names and locations are demonstration labels; no live
deployment data or receiver credentials appear in these images.

Captured from the published `main` application on 2026-10-17 in English and
Brazilian Portuguese at a 1440 × 930 viewport. The application and broker came
from the published Compose images after an explicit pull. The short demo command
in the main README publishes a single device, so its initial overview is smaller.

When refreshing these images, use a separate database and broker, publish simulated
samples, register the devices, and capture both languages. Keep product screenshots
separate from the component gallery in `docs/brand`.
